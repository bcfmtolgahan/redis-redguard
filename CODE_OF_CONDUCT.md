# Code of Conduct

This project follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: treat other people with respect. Technical disagreement is welcome and is settled with reasoning, measurements and tests. Harassment, personal attacks, and publishing someone's private information are not acceptable, in issues, pull requests, commit messages or any other project space.

Maintainers remove, edit or reject contributions that do not follow this code, and may block accounts that keep breaking it.

## Reporting

Report conduct concerns to the maintainer, [@bcfmtolgahan](https://github.com/bcfmtolgahan), through GitHub. Reports are handled privately. If the concern is about a maintainer, use [GitHub's abuse reporting](https://github.com/contact/report-abuse) instead.
